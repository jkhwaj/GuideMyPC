## קטגוריות תרומה לתיעוד

יש לבחור ולפרט רק קטגוריות שבוצעו בפועל:

- ניתוח דרישות, הגדרת היקף ותכנון.
- פיתוח צד שרת, אבטחה ולוגיקה עסקית.
- תכנון מסד נתונים, migrations ונתוני seed.
- פיתוח ממשק, עיצוב רספונסיבי ושיפור חוויית משתמש.
- בדיקות אוטומטיות, בדיקות ידניות ותיקון תקלות.
- תיעוד טכני, UML, דוח, צילומי מסך והכנת חבילת ההגשה.
- ביקורת קוד, ביקורת מסמכים ואימות תוצרי הגשה.

## הצהרת תרומות

- יש לתאר את חלוקת העבודה בפועל בלבד ולהתאים אותה להיסטוריית Git ולתוצרים שהוגשו.
- לכל חבר/ת יש לציין תפקיד, תחומי אחריות, תוצרים שבבעלותו/ה ותחום שבוצעה עליו ביקורת.
- אחוזי התרומה, אם נדרשים, צריכים להסתכם ל-100% ולהתבסס על עבודה ממשית ולא על מספר ה-commits בלבד.
- לפני ההגשה יש לוודא שהפרטים במסמך זה תואמים ל-`Readme.docx` ולדוח הסופי.
- אין להחליף את מצייני המקום במאגר הציבורי. את השמות, מספרי הזהות ופרטי הקשר יש להשלים רק ב-`Readme.docx` הפרטי, אם דרישות הקורס מחייבות זאת.
