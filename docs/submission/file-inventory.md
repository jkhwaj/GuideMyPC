## Codes

| Code | Meaning |
| --- | --- |
| `BASE` | Composer strict validation, current PHP source lint, fast tests and full isolated-DB verification. |
| `HTTP` | Apache route matrix: method, status, content type, role, CSRF, redirect, session and side effects. |
| `404` | Remove all inbound references and prove the old URL returns the standard safe 404. |
| `DB` | Fresh migration, representative upgrade, no-op second migration, repeated seed and full `_test` suite. |
| `PKG` | Strict package, prohibited-content scan and clean-extraction installation. |
| `UI` | Desktop, tablet, 320x800, keyboard, focus, reflow and reduced-motion review. |
| `R-route` | Restore the wrapper, route-map entry, callers, contract and tests as one change. |
| `R-slice` | Restore every file/reference/test in the retired feature slice; do not restore only one layer. |
| `R-doc` | Revert the documentation change while preserving newer evidence in Git history. |
| `R-db` | Never edit/down historical SQL; restore an approved backup or add a tested forward fix. |

Decisions describe the approved release target, not permission to change a file
before its row and the reorganization plan are reviewed. Historical migrations
remain byte-for-byte immutable even when their dormant feature is excluded.
