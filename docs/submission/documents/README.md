# Final Word Documents

Keep the two instructor-facing Word files in this directory on your local machine:

```text
Readme.docx
GuideMyPC-Final-Report.docx
```

`Readme.docx` must contain the project and group details required by the course. `GuideMyPC-Final-Report.docx` must follow `docs/submission/report-outline.md` and describe the exact submitted commit.

These files are ignored by Git because they may contain personal information. The strict submission package command requires both files and copies them into the final ZIP.
