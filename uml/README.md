# UML Deliverables

The course submission requires four UML diagrams and the editable Visual Paradigm project. Keep the final binary files local and ignored by Git. The submission packaging command copies them into the final ZIP.

```text
uml/
|-- source/
|   `-- GuideMyPC.vpp
`-- exports/
    |-- use-case.png or .pdf
    |-- class-diagram.png or .pdf
    |-- activity-diagram.png or .pdf
    `-- state-machine.png or .pdf
```

The diagrams must match the submitted implementation:

1. Use Case Diagram, supported actions for guest, registered user, editor, and administrator.
2. Class Diagram, implemented domain entities and their relationships.
3. Activity Diagram, one complete user process with decisions and failure paths.
4. State Machine Diagram, a lifecycle that exists in the application.

Export readable images or PDFs and review every label before building the strict submission package.
